# German function words, pronouns, discourse markers, and the ordinary nouns
# that capitalise only because German capitalises every noun.
#
# The second group is why this file exists. A language-agnostic capitalisation
# test cannot tell "Aber" from "Anthropic", because German capitalises every
# noun as a spelling rule rather than as a signal of a proper name. So the nouns
# have to be spelled out. Entries are LEMMAS: `lang_resources` strips up to two
# German inflection suffixes before looking a token up, so `Universums` matches
# `universum` and `Modellen` matches `modell`.
#
# Deliberately not enormous. One signal among several — corroboration (seen
# more than once, or in speech and on screen) and category vocabulary do the
# rest — so a missing noun costs one false candidate, not a broken filter.
#
# The nouns above the marker are ordinary vocabulary added from observed
# transcripts — each one was a false positive in a real report before it was
# listed here. The list grows this way on purpose: it is the designed
# maintenance path, and an entry with a known origin can be argued with.
# A word missing from it costs one false candidate, not a broken filter.
